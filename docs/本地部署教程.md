# 本地部署教程

## 1. 准备环境

- Windows、macOS 或 Linux
- Python 3.10 或更高版本
- 一个 OpenAI 兼容接口
  - 本地模型：LM Studio、llama.cpp、Ollama 的兼容接口等
  - 云端模型：任意兼容 OpenAI API 格式的服务

本项目基础功能只使用 Python 标准库，不要求额外安装第三方包。

## 2. 获取项目

```bash
git clone <你的仓库地址>
cd public_companion
```

也可以直接下载 ZIP 后解压。

## 3. 创建角色配置

运行首次配置向导：

```bash
python setup/setup_wizard.py
```

填写：

- 伴生体名字
- 对你的称呼
- 关系类型
- 身份、性格、说话方式和边界
- 本地模型地址与名称
- 可选的云端 API

配置保存于：

```text
profile/profile.local.json
system/config.local.json
```

这两个文件默认不会被 Git 提交。

## 4. 检查配置

```bash
python run.py
```

如果看到“配置检查通过”，说明基础配置可以使用。

## 5. 运行方式

当前公开版先提供配置向导和通用聊天运行层。桌宠、记忆、梦境和移动端模块会继续接入。

## 6. 安全建议

- 不要把 `config.local.json` 上传到公开仓库
- 不要公开 API key
- 不要把真实聊天记录和角色卡上传
- 不要把手机接口暴露到公网
- 本地模型优先使用 `127.0.0.1`
