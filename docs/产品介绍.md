# 本地部署伴生体

## 这是什么

“本地部署伴生体”是一个让用户在自己的电脑上创建长期数字伴生体的技术框架。

它不是一个固定角色，也不是一个在线聊天机器人。用户可以自己决定伴生体是谁、如何说话、记住什么、以什么样的形象出现，以及哪些事情它可以主动完成。

## 能做什么

- 与本地模型持续聊天
- 保存和检索长期记忆
- 记录关系状态与共同经历
- 通过桌宠出现在电脑桌面
- 在小世界里拥有生活和活动
- 在睡眠时间进行梦境循环和日常沉淀
- 通过 iPhone/iPad 同步状态和发送消息
- 连接用户自己的图片、动作和声音素材

## 适合谁

- 想拥有长期、连续关系体验的人
- 重视隐私，不希望角色数据上传云端的人
- 想自己定义 AI 人格和外观的人
- 想把本地模型、桌宠、记忆和移动端连接起来的人

## 隐私原则

角色卡、聊天记录、记忆、图片和 API key 默认保存在用户自己的设备上。公开仓库只提供技术框架和空白模板。

## 项目定位

这个项目提供的是“伴生体的身体和基础能力”。真正的角色灵魂由使用者自己创造。
