# Local Digital Companion Engine

这是一个本地运行的 PySide6 数字伴生体框架，提供聊天、记忆、受限工具、可选自主行为、房间场景和透明桌宠等功能。

## 公开版边界

- 本仓库不包含作者的人设、聊天记录、关系数据、照片、视频、图片或桌宠立绘。
- `core/` 只有通用能力说明；首次启动会从空白配置开始。
- 用户在「伴生体工坊」填写自己的名字、人设和模型地址，并上传自己的场景与桌宠素材。
- `memory/`、`workspace/`、`logs/` 等运行数据只在本机生成，默认不应提交到 Git。

## 启动

1. 安装 Python 3.11+ 和依赖：`pip install PySide6 requests pillow`。
2. 如需本地模型，在 `system/config.json` 中填写 OpenAI 兼容服务地址和模型名；也可以保持空白后再配置。
3. 运行 `python src/main.py`。
4. 打开「伴生体工坊」，填写人设并上传场景视频/图片和透明桌宠 PNG。

公开版默认不会自动启动模型服务，也不启用窗口感知；需要时在本地配置中自行打开。
