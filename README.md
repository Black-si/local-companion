# Local Digital Companion Engine

这是一个本地运行的 PySide6 数字伴生体框架，提供聊天、记忆、受限工具、可选自主行为、房间场景和透明桌宠等功能。

## 公开版边界

- 本仓库不包含作者的人设、聊天记录、关系数据、照片、视频、图片或桌宠立绘。
- `core/` 只有通用能力说明；首次启动会从空白配置开始。
- 用户在「伴生体工坊」填写自己的名字、人设和模型地址，并上传自己的场景与桌宠素材。
- `memory/`、`workspace/`、`logs/` 等运行数据只在本机生成，默认不应提交到 Git。

## 启动

1. 安装 Python 3.11+ 和依赖：`pip install PySide6 requests pillow`。
2. 如需本地模型，在 `system/config.json` 中填写 OpenAI 兼容服务地址和模型名；也可以保持空白后再配置。
3. 双击 `run.bat`，或在项目目录运行 `python src/main.py`。
4. 打开「伴生体工坊」，填写人设并上传场景视频/图片和透明桌宠 PNG。

### 兴趣与互联网感知

在工坊的「人设与兴趣」页填写兴趣关键词（用逗号或顿号分隔）。互联网感知和热搜注入只会保留命中这些关键词的标题；留空时不会把通用热搜当成伴生体自己的兴趣。

### 小世界与 Godot

Godot 房间是可选的渲染模块，不是运行前置条件。没有安装 Godot 或房间工程时，仍可使用聊天、桌面、桌宠、记忆和文字状态；安装后再把房间模块放入 `worlds/chen_world/godot_room_v1`，即可从「空间」页进入画面。

公开版默认不会自动启动模型服务、后台意识循环或窗口感知；配置好本地模型并重启后，才会启动完整生命循环。

在工坊填好 LM Studio / Ollama 地址后点击「测试模型连接」，它会读取 `/v1/models` 并自动带入第一个模型名。测试成功后保存并重启，聊天和后台生命循环才会真正工作。

手机接口同样默认关闭，不会自动在局域网开放端口。需要手机或快捷指令时，在「修理台 → 设备与连接」勾选启用，然后重启伴生体；接口会使用本机生成的随机 Token 认证。
