# 本地部署伴生体

一个以本地部署为核心的伴生体框架。

用户可以在自己的电脑上定义伴生体的名字、人格、关系、外观、记忆和模型接口。角色数据、聊天记录和 API key 默认只保存在本机。

## 设计目标

- 本地优先：聊天和记忆可以完全在本机运行
- 可替换模型：支持 OpenAI 兼容的本地接口，也可选云端 API
- 用户自定义：人格、图片、动作和关系都由用户自己配置
- 低门槛：首次启动通过配置向导完成设置
- 隐私边界清晰：公开的是技术框架，个人角色数据独立保存

## 目录

```text
src/       通用运行代码
setup/     首次配置向导（开发中）
system/    配置模板
profile/   角色配置模板
assets/    示例素材
memory/    本地运行后生成，默认不提交
logs/      本地运行后生成，默认不提交
```

## 安全说明

不要把真实 API key、聊天记录、人格原文、私人图片或 `memory/` 上传到公开仓库。先复制 `system/config.example.json` 为本地配置，再填写自己的信息。

## 当前状态

当前目录是公开版基础骨架。可以先运行：

```powershell
python setup/setup_wizard.py
python run.py
```

配置向导和配置加载器已经可用；通用桌宠、记忆存储、梦境循环和移动端接口会在后续逐步接入。
